# Insurance Cost Predictor

GitHub: https://github.com/yinruide/Insurance-Cost-Predictor

Insurance Cost Predictor is a neural-network and machine-learning prediction system that estimates annual insurance costs.

## System Features

- Uses original saved model artifacts where available.
- Estimates annual insurance costs from user input features.
- Provides uncertainty signals and prediction bands.
- Shows feature drivers behind the prediction.
- Includes model comparison views.
- Wraps the original Streamlit project with a backend so the portfolio can present a product-style dashboard UI.

The project connects machine-learning modeling with practical health-finance product design.
