# Responsible AI Notes

- Responsible agents should expose limitations.
- They should not invent unsupported claims.
- They should distinguish project evidence from general opinion.
- They should retrieve context before answering project-specific questions.
- They should verify claims.
- In biomedical contexts, they should avoid giving medical advice.
- In decision-support contexts, they should clarify assumptions and uncertainty.
- Agent reliability should include controllability, robustness, reproducibility, transparency, and user attention cost.
